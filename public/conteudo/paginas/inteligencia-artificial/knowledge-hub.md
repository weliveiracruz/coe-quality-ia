# Knowledge Hub e RAG

O Knowledge Hub é a documentação viva do COE e da RT.

## O que entra
- metodologia
- indicadores
- troubleshootings
- padrões
- decisões
- incidentes
- aprendizados

## Para onde vai
Depois, esse conteúdo pode virar a base de conhecimento para RAG e agentes internos. Este site já guarda todo o conteúdo em Markdown versionado no Git, o formato mais simples para essa evolução.
