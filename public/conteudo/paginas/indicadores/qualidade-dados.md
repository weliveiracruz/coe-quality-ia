# Qualidade de dados e linhagem

## O que acompanhamos
- qualidade dos dados
- validação de regras
- consistência das apurações
- análise de anomalias
- linhagem dos dados até o indicador publicado

## Missões
Quando surge uma inconsistência num indicador, o COE pode entrar numa missão com a squad para encontrar a causa e resolver. Depois, deixa automação, monitoramento e documentação.

> Exemplo: "Temos inconsistência no indicador X."
