# Quality Engineering Kit

**Objetivo:** uma squad ou um produto novo não começar a qualidade do zero.

## O que tem no kit
- templates
- guidelines
- pipelines
- exemplos
- checklists
- automações
- DoD
- padrões

## CoE Test Framework
O primeiro componente do kit é o CoE Test Framework. Ele traz:
- templates de teste para Android, iOS, BFF Kotlin, API .NET, Angular e React
- pipelines no GitHub Actions com SonarQube
- contratos, suítes transversais (LGPD, resiliência, acessibilidade) e o portal de adoção

Baixe o pacote e veja como usar na [página do CoE Test Framework](/qualidade/coe-test-framework).
